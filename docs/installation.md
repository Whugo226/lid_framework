# Installation

## Stable release

To install LID Toolkit, run this command in your terminal:

```sh
uv add lid_toolkit
```

Or if you prefer to use `pip`:

```sh
pip install lid_toolkit
```

## From source

The source files for LID Toolkit can be downloaded from the [Github repo](https://github.com/Whugo226/lid_toolkit).

You can either clone the public repository:

```sh
git clone git://github.com/Whugo226/lid_toolkit
```

Or download the [tarball](https://github.com/Whugo226/lid_toolkit/tarball/master):

```sh
curl -OJL https://github.com/Whugo226/lid_toolkit/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd lid_toolkit
uv pip install .
```
